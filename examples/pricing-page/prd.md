## 1. 执行摘要

为**中小团队协作 / 项目管理工具**（ICP：5–50 人团队）新建一张**官网公开定价页**，让团队负责人能自行比较四档套餐的价格与权益，并通过「预约演示」发起联系。

**关键背景**：本页为**纯销售导向**——全页无任何自助注册或试用入口，公开价格只承担**筛选线索与锚定预算**的作用，不承担成交。这一点决定了 CTA、指标与页面终点，与「参考 Stripe」的原始输入存在刻意差异（见第 4 节）。

**预期影响**：产出一张可独立上线的营销页；全页唯一转化动作是提交销售线索。

## 3. 问题与用户

### 目标角色 / 用户

| 角色 | 说明 |
| --- | --- |
| **团队负责人 / 部门主管（主角色）** | 5–50 人团队中实际决定购买的人。关心「好不好用、值不值这个价」，不关心采购流程或招标 |
| **销售** | 页面产生的全部线索的唯一去向 |
| 未登录访客 | 可访问、可比较，但无任何自助购买或自助注册入口 |

### 问题与证据

- 无公开定价页，价格只能由销售口头解释，客户在初次接触前对成本没有预期
- 销售每次都要从零解释定价，重复沟通成本高
- 「公开价格能筛选线索质量」是本页的核心假设，**尚未被验证**

### 要完成的任务 / 当前行为

- **待完成的任务**：团队负责人需要在**不联系销售的前提下**先自行判断「大致要花多少钱、我们落在哪一档」，再决定是否值得投入一次演示沟通
- **当前行为**：`[UNKNOWN]` —— 未采集客户目前如何获知价格

## 4. 战略背景

- **目标 / 为什么是现在**：
  - 交付窗口：本月底
  - 商业定位：**纯销售导向**，销售线索是唯一产出
  - 定价模型：固定一口价 × 3 档，不按席位、不按用量；另设企业版走「联系销售」
- **相关背景**：
  - 原始输入为「参考 Stripe 的定价页」。Stripe 定价页的核心是**自助转化**（公开价 + 试用 + 自助开通），本页已改为销售导向，**形态可参考、目的不可照搬**
  - 价格数字为拟定值，**没有竞品调研支撑**（见第 8 节风险 3）

## 5. 范围与方案

### 定价与权益

固定一口价，按团队计，不随席位数变化。

| 档位 | 月付 | 年付 | 年付折算月价 | 人数上限 | CTA |
| --- | --- | --- | --- | --- | --- |
| 基础版 | ¥99 / 月 | ¥990 / 年 | ¥82.5 / 月 | 10 人 | 预约演示 |
| **专业版**（推荐） | ¥299 / 月 | ¥2,990 / 年 | ¥249 / 月 | 30 人 | 预约演示 |
| 旗舰版 | ¥899 / 月 | ¥8,990 / 年 | ¥749 / 月 | 100 人 | 预约演示 |
| 企业版 | 联系销售 | — | — | 不限 | 联系销售 |

- **年付 = 10 个月价格**，即省约 17%，默认选中
- **均为含税价**，页面需明示「以上价格为含税价」

**各档核心权益（每档 5–8 条）**

| 档位 | 权益 |
| --- | --- |
| 基础版 | 团队人数上限 10 人；无限项目与任务；看板 / 列表 / 日历三种视图；1 GB 附件存储；两级权限（成员 / 管理员）；30 天操作历史；邮件与站内通知；社区支持 |
| 专业版 | 含基础版全部功能，另加：团队人数上限 30 人；甘特图与任务依赖；自定义字段 + 20 条自动化规则；自定义角色与细粒度权限；50 GB 附件存储；无限期操作历史与版本回溯；第三方集成（飞书 / 钉钉 / 企业微信 / Slack，最多 5 个）；优先邮件支持（1 个工作日响应） |
| 旗舰版 | 含专业版全部功能，另加：团队人数上限 100 人；SSO 单点登录（SAML / OIDC）；无限自动化规则 + 跨项目自动化；审计日志与合规导出；500 GB 附件存储；公开 API 与 Webhook；自定义报表与仪表盘；专属客户成功经理 + 4 小时响应 |
| 企业版 | 人数无上限；私有化部署或专属实例；定制 SLA；数据隔离与私有云；安全与合规支持（等保 / SOC 2 问卷）；对公合同、发票，以及定制集成与数据迁移 |

### 范围内

1. 一张官网公开、未登录可访问、可被搜索引擎收录的定价页
2. 三张有价卡 + 一个视觉上可区分的企业版区块
3. 月付 / 年付切换（显示年付总价、折算月价、省幅）
4. 每档核心权益清单（**不做**逐项打勾的功能对比大表）
5. 计费与付款方式说明文字（**不做**用量估算器）
6. FAQ
7. 「预约演示」/「联系销售」表单 —— 全页唯一转化落点
8. 入口：官网顶部导航「定价」、首页价格 CTA

### 用户流程

1. **触发**：访客从官网顶部导航「定价」或首页价格 CTA 进入（未登录态）
2. **主要动作**：浏览卡片比较价格与权益 → 切换月付 / 年付读取省幅 → 阅读计费说明或 FAQ 消除疑虑
3. **结果 / 状态变化**：
   - 主路径：点击「预约演示」/「联系销售」→ 提交线索 → 由销售接手
   - 离开页面，不留资
   - **本页不产生任何账号、订单、订阅或支付状态变化**

### 范围外

| 排除项 | 理由 |
| --- | --- |
| 支付、试用开通、账单管理 | 页面不碰钱 |
| 自助注册链路 | 纯销售导向，全页无自助入口 |
| 免费版（Free tier） | 最低档即付费 |
| 多币种与多语言 | 只出单币种（¥）、单语言 |
| 优惠券与促销码 | 不做折扣码、限时促销、首年优惠 |
| 产品内升级 / 降级 / 续费入口 | 属另一条链路 |
| 用量估算器 | 改为文字说明 |
| 逐项打勾的功能对比大表 | 降级为核心权益清单 |
| 产品内登录态差异处理 | 本页不区分登录与否 |

### 待定（未经确认，不得当作已承诺）

- 客户 logo 墙 / 评价 / 社会证明
- 竞品对比内容

## 7. 需求与验收

### R1. 浏览并比较四个档位

作为**团队负责人**，我可以在定价页一次看清四个档位的价格、人数上限与核心权益，以便判断哪个档位匹配我们的团队规模与预算。

验收标准：
- [ ] 页面呈现四张卡片：基础版 ¥99/月、专业版 ¥299/月、旗舰版 ¥899/月、企业版「联系销售」
- [ ] 每张有价卡显示：档位名、价格、人数上限、CTA 按钮（价格的默认形态见 R2）
- [ ] 每档显示 5–8 条核心权益条目，内容与第 5 节一致
- [ ] 推荐档（专业版）有明确视觉标记
- [ ] 企业版不显示任何价格数字，只显示「联系销售」
- [ ] 全页**不出现**任何自助注册、免费试用、立即购买的入口或文案
- [ ] 移动端不产生横向页面滚动；卡片在窄屏下纵向堆叠

### R2. 切换月付 / 年付

作为**团队负责人**，我可以切换月付与年付，以便判断年付能省多少、是否值得一次付清。

验收标准：
- [ ] 页面**默认选中年付**，首屏卡片即显示年付折算月价
- [ ] 切换后，三张有价卡的价格、折算月价、省幅**同步更新**，无残留旧值
- [ ] 年付态同时显示三样：年付总价、折算月价、省幅（约 17%）
- [ ] 月付态显示月付价；企业版卡片不受切换影响
- [ ] 切换不触发页面刷新或整页重载

### R3. 发起联系（本期核心转化动作）

作为**团队负责人**，我可以点击「预约演示」提交我的联系方式，以便与销售取得联系。

**表单字段**：姓名、企业邮箱、公司名、团队规模（下拉区间，非自由输入）
**隐私合规**：提交前必须勾选「我已阅读并同意《隐私政策》」，链接指向已有的隐私政策页

验收标准：
- [ ] 三张有价卡的 CTA 文案为「预约演示」；企业版的 CTA 为「联系销售」
- [ ] 两种 CTA 指向**同一个表单**（不出现两套重复表单）
- [ ] 表单**仅含四个字段**：姓名、企业邮箱、公司名、团队规模
- [ ] 隐私同意**不得默认勾选**；未勾选时提交被拒绝并给出提示
- [ ] 《隐私政策》链接可点击、指向已有隐私政策页
- [ ] 邮箱格式非法、必填项为空时，字段旁显示错误且不提交
- [ ] 具备基本防刷能力（邮箱验证或轻量验证码），且不阻断正常用户
- [ ] 提交成功后给出确认反馈，并明确承诺「1 个工作日内联系」
- [ ] 提交失败时给出可恢复的错误提示（网络失败、校验失败可区分）
- [ ] 全页不出现第二个转化动作

### R4. 阅读计费与付款方式说明

作为**团队负责人**，我可以阅读计费与付款方式的说明，以便判断这笔费用怎么付、能不能报销。

验收标准：
- [ ] 页面包含一段说明文字，覆盖计费周期、人数上限的处理方式、方案变更、发票与付款方式
- [ ] **公示价格明确标注为含税价**
- [ ] 不出现用量估算器或交互式计算工具
- [ ] 页面任何位置不出现内部未决表述

### R5. 查看 FAQ

作为**团队负责人**，我可以查阅常见问题，以便在不联系销售的情况下先消除基础疑虑。

验收标准：
- [ ] FAQ 至少覆盖：费用与付款方式、数据安全、人数上限与超额处理、方案变更、如何联系销售
- [ ] 不出现招标、采购流程、供应商入库类问题（与第 3 节角色定位一致）
- [ ] 展开 / 收起交互可用，键盘可操作
- [ ] FAQ 条目的答案与 R4 说明文字在事实上一致

### R6. 通过企业版区块发起咨询

作为**团队负责人**，当我们的团队规模或需求超出公开档位时，我可以从企业版区块直接发起咨询。

验收标准：
- [ ] 页面存在独立的企业版区块，与三张有价卡视觉上可区分
- [ ] 企业版区块列出 6 条权益，内容与第 5 节一致
- [ ] 企业版区块的 CTA 为「联系销售」，指向与 R3 相同的表单
- [ ] 移动端下该区块完整可见，不与相邻区块发生元素重叠

### R7. 页面可被访问与收录（非功能要求）

作为**团队负责人**（经由搜索引擎或官网导航进入），我可以正常打开并加载这张页面，以免因技术原因看不到价格。

验收标准：
- [ ] 页面可被搜索引擎收录：无 `robots` 屏蔽、含 `canonical` 标签、不在登录墙后
- [ ] 移动端 LCP（最大内容绘制）< 2.5 秒
- [ ] 近两年主流浏览器可用：Chrome / Edge / Safari / Firefox 各自最新两个大版本
- [ ] 关键词定位、结构化数据、无障碍达标等级本期未要求
