# PM Frontend Prototype

基于现有前端项目源码创建独立的项目内高保真原型。它复用真实页面外壳和组件，但默认不改正式业务入口。

## 何时使用

- 需要在真实 Admin / C 端语境中演示需求。
- 需要点击查看弹窗、表单、筛选、状态和完整操作路径。
- 项目已有页面、组件和设计 Token，需要保持视觉一致。

## 输入

- 现有前端项目源码、相邻页面和路由约定。
- PRD、产品体验基线或已确认的设计规格（如存在）。
- 产品经理希望评审的流程和页面状态。

## 产物

- 独立原型路由、页面或功能目录。
- 页面级模拟数据和本地交互状态。
- 可选的 `demo.md`，记录评审结论和推荐交付路径。

默认入口与正式业务页面隔离；只有用户明确要求时才修改现有业务入口。

## 不做什么

- 不默认接入真实 API、数据库、生产数据或复杂后端架构。
- 不从零复制一套脱离项目的静态网站。
- 不把一次性原型模式自动抽成全局组件。

## 下一步

评审确认后交给研发按原型实现。
