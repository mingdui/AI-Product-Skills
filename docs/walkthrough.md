# 一次完整的真实运行

这不是示意图。下面是一条**真跑过**的链路：从一句口头需求，到一份 PRD，再到一个能点的原型。

- 运行日期：2026-10-13
- 演示题材：给一个 SaaS 产品做**定价页**，参考 Stripe
- 产物：[`examples/pricing-page/`](../examples/pricing-page/) —— 四个文件，全在里面
- 想直接看结果：用浏览器打开 [`examples/pricing-page/prototype.html`](../examples/pricing-page/prototype.html)

> 产物里的价格与权益都是**占位数据**，是演示用的，不是真实结论。

---

## 一、跑了哪五个步骤

| # | 命令 | 产物 |
| --- | --- | --- |
| 1 | `/requirement-clarify pricing-page` | `clarify.md` |
| 2 | `/prd-write pricing-page` | `prd.md` |
| 3 | `/grill-with-prd pricing-page` | 写回 `prd.md` |
| 4 | `/web-design-extractor https://stripe.com/pricing` | `design.md` |
| 5 | `/design-spec-prototyper pricing-page` | `prototype.html` |

五个步骤、四个产物，**全部落在同一个目录**里，没有一次手工拷贝。
这就是 `docs/prd/<feature-name>/` 这个约定的全部意义。

## 二、每一步实际发生了什么

### 1. 需求澄清

**输入**是一句话：

> 竞品都有定价页，我们没有。用户问价格只能找销售，转化太低。做个定价页，参考 Stripe 那种，这个月底上线。

`requirement-clarify` 按五类信息（目标角色 / 触发场景 / 范围 / 明确不做 / 已知约束）整理，
答不上来的记成 `[UNKNOWN]` + 归属人。

**这一轮最值钱的产出是「明确不做」**：一口气排除了在线支付、优惠券、年付切换、多币种、
后台配置界面。这一条直接决定后面 AI 会不会自己补全出没人要的范围。

留下 3 条 `[UNKNOWN]`（套餐价格、企业档口径、降级入口），**没有一条被编成事实**。

### 2. 写 PRD

读 `clarify.md`；查 `docs/product/` —— 不存在，于是记录「无产品基线」，不虚构产品级规则。
因为是本产品第一个对外页面，走 `full` 完整模式。

### 3. 压测 PRD（这一步最不该省）

`grill-with-prd` 逐条质疑，确认一条就立刻写回原文。它问出了 **5 个真问题**，
其中 3 条是**这份 PRD 在打自己**：

| 问题 | 处理 |
| --- | --- |
| §8 说「本期无后端接口」，§7 却要求「已登录用户看到自己当前的档位」 | 删掉该条，整段移入范围外，写明「标错比不标更伤」 |
| §3 说用户主要从搜索引擎、社交分享进来，范围里**完全没提 SEO 与分享预览** | 新增 R5：收录 + Open Graph 预览 + 禁 JS 仍可读 |
| §6 要测「定价页 → 注册」的转化率，§7 **没有任何一条要求埋点** | 新增 R6：曝光 / CTA / 分组展开 / FAQ 展开，且要带来源渠道 |
| §9 说企业档口径未定，§7 却已写「每档含价格」 | R1 验收补一条：三档口径必须统一 |
| 验收标准只有正常流程 | 补「通用验收」：键盘可达 + 焦点可见 + 纯静态无加载/错误态 |

**自己写的 PRD，自己通读一遍是看不出这些的。**

### 4. 提取设计规格

从 `https://stripe.com/pricing` 提取带证据的 `design.md`。

这次**没有浏览器控制能力**，只能读服务端返回的 HTML 和其中声明的 CSS——按
[`web-design-extractor` 的降级路径](../skills/web-design-extractor/SKILL.md) 走：
`design.md` 开头写明「转录边界」，令牌值记 `[OBSERVED: URL]`，
「哪个令牌用在哪个元素上」一律 `[INFERRED]`，断点与交互态全标 `[UNKNOWN]`。

提取到的东西（示例）：品牌强调色 `#635bff`、深色文本 `#0a2540`、圆角 4/6/8/16.5/99px、
阴影 `0 20px 60px rgba(50,50,93,.18)`、导航容器高 64px 最大宽 1264px，
以及**最值得借的那一条交互**——全功能对比按能力分组、可折叠。

`design.md` 同时写明了**不沿用**对方的品牌色与字体，并说明了理由。

### 5. 生成原型

`design-spec-prototyper` 读 `design.md` + `prd.md`，把令牌定义成 CSS 自定义属性，
按 R1–R6 逐条实现，产出 `prototype.html`——单文件、26 KB、零外部依赖。

每条需求都能在页面上指出来：

| PRD | 在原型里 |
| --- | --- |
| R1 浏览套餐与价格 | 三档卡片，主推档加标签与描边；三卡按钮对齐同一基线 |
| R2 全功能对比 | 4 个按能力分组的折叠区块，取值写「有 / 无 / 数值」而不是留空 |
| R3 行动按钮 | 三档 CTA 各异；未登录点专业档先跳登录 |
| R4 常见问题 | 4 条 `<details>`，原生可键盘操作、展开态对读屏可见 |
| R5 收录与分享预览 | title / description / Open Graph / Twitter Card；**禁用 JS 时正文全在** |
| R6 关键动作埋点 | `track()` 桩函数，包在 `try/catch` 里，失败不阻塞跳转 |

字体来源是 `system`——参考站的字体不能沿用，本页又是中文内容且要求离线可读。

## 三、怎么验证的

不是「声称检查过」，是真跑了：

| 检查 | 结果 |
| --- | --- |
| 静态 | 乱码 0 处；12 个 id 无重复；4 个 `aria-controls` 全部命中；标签全部闭合 |
| 标题层级 | 整页只有 1 个 `<h1>` |
| 渲染 | Chrome headless 真实截图，1440 / 1024 / 375 三个视口都成立 |
| 交互 | 程序化触发后读回：4 个分组全部折叠成功、`hidden` 正确落到 4 个内容体、FAQ 可展开、埋点队列记到 5 条 |
| 几何 | 三张卡片 `top` 完全相等；`scrollWidth == clientWidth`，无横向溢出 |

**没做到的也如实说**：

- 没有真人键盘 / 读屏实测——只验了 DOM 属性与程序化 click，没按 Tab 走一遍
- 只测了 Chrome，没测 Safari / Firefox
- 两处已知可优化但本次没改：企业档「按需报价」与另两档价格在视觉权重上偏接近；
  窄屏下对比表默认只露出第一列，要横滑才能看到后两档

## 四、这轮跑下来改了什么

跑的过程中暴露了几个 skill 本身的问题，已经全部修掉（详见 [CHANGELOG](../CHANGELOG.md)）：

1. **`context-to-prd` 和 `prd-write` 原本各有一套 PRD 模板**，结构完全不同却写同一个
   `prd.md`——下游按哪套找章节没有答案。现已统一到 `prd-write/template.md`，
   并明确「二选一，不要连着跑」。
2. **`web-design-extractor` 假设了「有浏览器控制能力」却没给降级路径**，
   没有浏览器时会静默退化成读源码，而交付物看不出区别。现已补上降级路径与标注要求。
3. **`prd-write/template.md` 第 0 节的「关联产物」有顺序矛盾**（PRD 先写，原型后做）。
   现已写明「原型做完再回填」。
4. **`requirement-clarify` 和 `grill-with-prd` 都是交互式的**，演示与回归没法无人值守跑完。
   现已补「自答模式」，并要求把「自答」的部分单独列出来，不能伪装成用户确认。
5. **`design-spec-prototyper` 没说清「只有规格没有图」时构图证据由谁承担**。现已写明。
6. **中文在这个环境里会被吞字**——本次写 `prd.md` 时「站外访客」的「外」变成了两个
   U+FFFD，写文件阶段没有任何报错。现已在 `CLAUDE.md` 里要求所有会写中文产物的 skill
   把乱码扫描写进「交付前检查」。

## 五、结论

- 目录约定（`docs/prd/<feature-name>/`）是这条链路的骨架，它确实管用——**零手工搬运**。
- `grill-with-prd` 是分水岭，它从一份看起来挺完整的 PRD 里问出了 3 处自相矛盾。
- 证据分级不是形式主义。`[OBSERVED]` / `[INFERRED]` / `[UNKNOWN]` 分开标之后，
  一眼能看出哪些能当约束用、哪些只是默认值。
- 产物能真跑，但**别把没验的部分说成验过了**。见第三节末。
